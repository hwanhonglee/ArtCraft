# Windows에서 사용하기

## 편집 앱을 쓰기만 할 때

Git, Rust, Node.js 없이 설치 파일로 시작할 수 있습니다.

1. [공식 앱 목록](https://getartcraft.com/apps) 또는 [Launcher 최신 Release](https://github.com/storytold/craft-launcher/releases/latest)를 엽니다.
2. Intel/AMD 64비트 PC는 `windows-x64.msi`를 선택합니다. Windows on Arm은 `windows-arm64.msi`를 고릅니다.
3. MSI를 실행해 설치한 뒤 시작 메뉴에서 앱을 실행합니다.
4. 설치 없이 시험하려면 `portable.zip`을 별도 폴더에 풀고 앱 EXE를 실행합니다.
5. 기존 작업 파일은 사본으로 시험하고 새 파일로 저장한 뒤 원래 프로그램에서 재확인합니다.

## 포크한 코드를 수정·빌드할 때

1. [Git for Windows](https://git-scm.com/downloads/win)를 준비합니다.
2. [Rust](https://rustup.rs/)의 최신 stable MSVC 툴체인을 준비합니다. core 패키지의 최소 버전과 UI 요구 버전은 다를 수 있으므로 현재는 **Rust 1.95 이상**을 사용하세요.
3. [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)의 **Desktop development with C++ / C++를 사용한 데스크톱 개발** 구성 요소를 준비합니다.
4. 새 PowerShell 창에서 확인합니다.

```powershell
git --version
rustc --version
cargo --version
```

5. 원하는 작업 폴더에서 소스를 받습니다.

```powershell
git clone --recurse-submodules --depth 1 --shallow-submodules https://github.com/hwanhonglee/ArtCraft.git
cd ArtCraft
git submodule status
```

6. 한 앱의 폴더에서 빌드·실행합니다. PhotoCraft 예시:

```powershell
cd apps/photocraft
cargo run --release -p photocraft
```

### 글꼴과 추가 의존성

공식 설치 파일과 소스 빌드의 글꼴 포함 범위는 다를 수 있습니다. 앱들이 안내하는 `craft-fonts`의 상대 위치를 맞추려면:

```powershell
# ArtCraft 루트에서 실행
git clone https://github.com/storytold/craft-fonts.git apps/craft-fonts
$env:CRAFT_FONTS_DIR = (Resolve-Path apps/craft-fonts).Path
```

`craft-fonts`는 13개 포크 밖의 선택적 원본 의존성입니다. 한국어 UI 번역, 한글 입력, 글꼴 표시, PDF 내보내기는 서로 다른 항목이므로 앱별로 확인하세요.

실행이 막힐 때 보안·회사 정책을 임의로 바꾸지 말고 오류와 로그를 확인하세요. 빌드가 목적이 아니면 공식 설치 파일로 사용하면 됩니다.

## AI 스튜디오와 구분하기

별도의 [ArtCraft AI 스튜디오](https://github.com/storytold/artcraft)는 Rust/Tauri와 Node.js 기반 개발 환경을 사용합니다. 위 13개 앱과 실행 방법이 다릅니다.

[공식 가격 안내](https://getartcraft.com/pricing)의 AI 생성 크레딧·외부 구독·연산 비용은 포크와 별개입니다. 이 허브는 API 키·구독을 설정하지 않습니다.
